01 · Structure

구조 비교

Kong → Azure API Management, Kibana/Elasticsearch → Azure Monitor 대응표입니다. 왼쪽 굵은 선은 현행(레거시), 오른쪽은 전환 대상입니다.

게이트웨이: Kong → API Management

로그·모니터링: Kibana/Elasticsearch → Azure Monitor

04 · Reference

KQL 레퍼런스

Azure Monitor/Kusto 공식 "KQL 빠른 참조" 문서에 실린 연산자·함수를 전부 가져와, 쉬운 말 설명과 예시로 다시 정리했습니다. 주의: Kibana의 검색창 문법(Lucene/Kibana Query Language)도 약어가 "KQL"이지만, 여기서 다루는 Azure의 KQL은 전혀 다른 언어인 Kusto Query Language입니다.

09 · Local Test Lab

랩 개요

Azure 실 접속 권한 없이도, 샘플 Kong 설정과 그 APIM 대응 정책을 로컬 mock 엔진으로 실행해 결과를 비교합니다. 이 페이지의 샘플 데이터를 아래 4개 탭이 공유합니다.

10 · Local Test Lab

API 테스트

샘플 라우트를 선택하고 값을 입력해 실행하면, 같은 요청에 대해 Kong mock과 APIM mock이 각각 어떻게 응답하는지 나란히 비교합니다.

11 · Local Test Lab

APIM Policy

정책 XML을 직접 편집해서 실행해 보세요. 화이트리스트 7개 정책(check-header, rate-limit, cors, set-header, rewrite-uri, ip-filter, return-response)만 실제 동작을 시뮬레이션하며, 그 외 태그는 구문은 인정하되 "미지원" 배지로 표시합니다.

12 · Local Test Lab
